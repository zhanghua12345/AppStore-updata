# AppStore-updata

金币、金币包和会员的 Excel 生成、校验与上传工具。

## 最快使用方法

1. 直接双击根目录的 `index.html`，不需要打开 Xcode，也不需要启动服务器。
2. 选择一个或多个 `.xlsx`，再选择商品类型、价格、权益档位和操作范围。
3. 点击“生成完整指令”并复制。
4. 把指令粘贴到本项目的 Codex 对话中；Codex 会按项目 skill 展开价格、后缀、权益和关联页。

`index.html` 是离线操作台，只生成操作指令，不读取 Excel 内容，不保存密钥，也不会直接上传。

## 不打开 Xcode 上传

- 日常生成方案、修改 Excel 和校验：直接使用 `index.html` 和 Codex，不需要 Xcode。
- 真正上传 App Store Connect：可以直接双击已经编译好的 `AppleParty.app`，日常不需要打开 Xcode。
- 当前仓库没有编译好的 `.app`。首次构建仍需要一台安装完整 Xcode 的 Mac，也可以使用命令行构建而不打开 Xcode 界面。
- 单独的静态 `index.html` 不能安全直传 App Store，因为浏览器跨域限制且不应接触 `.p8` 私钥。

- [上传操作说明](./上传操作说明.md)：从生成 Excel、校验，到 AppleParty 上传和运营后台导入的完整中文说明。
